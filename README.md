## 👋 A little about me

Hi, I'm **Noah** — a full-stack developer and Computer Information Systems student at the **Federal University of Technology, Akure (FUTA)**, based in **Lagos, Nigeria**.

I enjoy building software that solves problems people around me actually have. When finding off-campus housing near FUTA became a maze of WhatsApp groups and word of mouth, I built **[Off-Campus Hub](https://offcampushub.ng)**: a production platform for listings, roommate matching, landlord dashboards, and student-friendly discovery.

I care about the complete product, not just the first screen: thoughtful UX, reliable APIs, useful data models, responsive interfaces, deployment, and the small details that make software feel finished. I am currently open to **internships, freelance work, and collaborations**.

## 🧭 How I like to work

- **Solve the real problem first.** Start with the people and context, not the trendiest stack.
- **Ship the whole thing.** Move comfortably from schema and API design to UI, deployment, and polish.
- **Keep it fast and understandable.** Prefer clean, maintainable solutions that work well on everyday devices.
- **Learn by building.** The best way I have found to learn a technology is to use it for something real.
